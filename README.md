# Dot Link

Build a web application for creating and managing short URLs.

Target users:

Creators, marketers, agencies and small businesses.

Core user flow:

1. User enters a long URL.

2. System validates the URL.

3. System generates a unique short code.

4. User receives the short URL.

5. Visiting the short URL redirects to the original URL.

6. User can view analytics for each link.

MVP features:

- Create short link

- Custom alias

- Copy short link

- Link list/dashboard

- Click count

- Unique visitor count

- Referrer

- Device

- Country

- Clicks over time

Do not add:

- AI

- Payments

- Team collaboration

- Complex permissions

- Browser extensions

Build the MVP first. The Ui should look like the images i am adding
